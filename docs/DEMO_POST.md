# Demo post draft

Do not post this. The human publishes it.

Cross-chain swap quotes are hard to compare, and a deposit address is easy to fund by mistake.

Instinct Router now asks NEAR Intents 1Click for a dry quote, ranks it against Relay on output, fees, and ETA, and shows the deposit step with no address and sending turned off. The quote hash from that comparison is stored on a NEAR testnet contract so the routing decision can be checked later. No wallet is connected and no funds move.
