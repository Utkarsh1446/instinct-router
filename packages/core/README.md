# @instinct/router-core · 0.1.0

Portable exact-asset route planning, quote scheduling, provider adapters, ranking, and execution coordination interfaces. ESM JavaScript and TypeScript sources for declarations; no runtime dependencies.

`createDeBridgeAdapter({fetch,chains,clock?,pricingTtlMs?,estimatedCompletionMs?})` adds direct cross-chain DLN development estimates. Explicit mappings are required; all construction wallet/authority fields are omitted. It validates raw amounts and asset identities, discards returned transaction artifacts, and treats recommended output as conditional pricing with unknown full costs. No execution recipe is supplied. The hosted engine requires `debridgeRoutes: true` to opt in.

Configure explicit chain/provider mappings and reviewed capabilities. Discovery and bound quotes do not authorize wallet actions. Ranking preserves unknown costs/impact/timing as unknown. Composite routing needs explicit intermediates and corresponding wallets/capabilities. A registration can be `directOnly: true` to keep aggregators limited to the original pair. Capability hashing runs in bounded parallel batches. Only swaps consume the route slippage budget; bridge output floors carry forward unchanged.

`createRaydiumAdapter` prices Solana routes through the pinned Trade API. `createUniswapV3Adapter` reads Base pools directly at one fresh canonical block and verifies token decimals before accepting a quote. Its native ETH mapping is for pricing only. Both adapters return conditional previews with unknown full costs and no execution recipe. They do not establish universal token coverage or executable native-token wrapping.

Adapters can implement `prepare(PreparationContext): Promise<PreparedQuote>` to fetch amount-independent context for later legs. The router enqueues required first-leg work first, then at most four deduplicated preparations within the same comparison and scheduler. The returned quote closure must bind its own private evidence to that exact request and scope. The Uniswap adapter warms only the chain/header; actual pool simulation still receives the previous conservative output. Header evidence retains its original TTL and block-age cutoff, with at most one fresh header reload. No warm context survives into another comparison. `disablePreparation` is a trusted core benchmark option, not an SDK request parameter. Preparation and quote operations share cancellation, capacity and transport deadlines; direct adapters without preparation keep their ordinary behavior.

`MetadataCache` coalesces discovery loads with a cache-owned abort signal and independent caller cancellation/deadlines. Aborted transports keep their capacity until they actually settle; late values cannot populate the cache. `createProviderDiscovery` can supply the shared Aurora `tokenCatalog` loader. Pass one `createCctpDiscovery` instance as `discovery` to multiple CCTP adapters to share directed fee matrices and allowance data for at most five seconds. Fast-mode independent reads run concurrently. Wallet amounts, gas proofs, and firm quotes are checked per request; cached evidence retains its original observation time.

The execution coordinator requires trusted canonical recipes, fresh checks, independent receipt verification, and a durable compare-and-swap store. The sibling engine supplies an opt-in Base native ETH→USDC recipe; the server connects it to its single-host durable store and wallet-authenticated endpoints. The coordinator retains the approved request for restart review verification and requires fresh pricing plus explicit action-chain gas evidence. A registered immutable-terms recipe may allow at most 90 seconds for review while claim re-simulates the same action. Only neverclaimed READY plans cancel/expire; uncertain claimed actions retain their reservation. Exact canonical reverted-transaction evidence permits FAILED, and verified recipient credit permits COMPLETE. Append-only observation times and receipt evidence survive recovery. No component holds a user's signing key or broadcasts on the user's behalf. Cross-chain staged actions are not implemented by this coordinator.
